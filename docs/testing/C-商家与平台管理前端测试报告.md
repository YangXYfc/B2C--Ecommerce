## 1. 测试目标

验证 C 角色负责的商家中心和平台管理端能够启动、构建、按角色登录并连接真实后端；重点验证商家商品图片上传、管理员看板和两个后台的“悦选生活”统一品牌。

## 2. 测试范围

- 商家中心登录、品牌、商品发布页、本地图片上传与提交数据。
- 平台管理未登录拦截、管理员登录、品牌和统计看板。
- 两个前端的 TypeScript 检查及 Vite 生产构建。
- 与 D 的认证、分类、图片接口以及与 E 的管理员统计接口联调。

## 3. 本次不测试的范围

- 商家发布商品的最终 `POST` 被 Playwright 拦截，避免向开发库写入测试商品；因此没有验证真实商品落库和管理员审核后的完整闭环。
- 未逐页操作商家订单发货、退款处理、评价回复。
- 未逐页操作管理员用户/商家/商品审核、退款仲裁、轮播图和日志。
- 未执行跨浏览器、权限渗透、性能和生产部署测试。

- C 角色目前只有关键入口和图片上传的 E2E 自动化，店铺、订单、退款、评价以及管理员审核页面缺少浏览器级回归测试。

- 构建产物主代码块较大，后续可按路由拆包优化首屏加载，但不属于本次测试文档任务。
