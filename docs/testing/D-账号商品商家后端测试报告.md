## 1. 测试目标

验证 D 角色负责的认证、用户、地址、商家、店铺、分类、商品、SKU、库存、图片上传以及管理员用户/商家/商品审核接口，确认权限边界、异常处理和 MySQL 映射在测试环境中可运行。

## 2. 测试范围

- 注册、登录、个人资料、密码和角色权限。
- 地址增删改查和默认地址。
- 商家申请、店铺资料和商家身份。
- 分类、商品列表/详情、SKU、上下架和库存修改。
- 管理员用户状态、商家审核和商品审核。
- 图片上传、文件校验和全局异常响应。
- A/B/C 前端对 D 接口的实时联调结果。

## 3. 本次不测试的范围

- 未执行高并发库存写入、负载、长时间稳定性和灾难恢复测试。
- 未验证生产环境 JWT 密钥、HTTPS、对象存储和反向代理配置。
- 未测试真实第三方身份认证或消息通知，因为项目没有接入这些外部服务。
- A 端商品分页字段不匹配仅记录，不在本次测试任务中修改。

## 12. 已知问题

### D-CONTRACT-001：A 端与商品分页响应字段不一致

后端和 B 端使用 `list`，A 端只读取 `records`。后端接口本身返回成功，但 A 端核心商品链路失败。应由 A/D 共同固定统一分页契约，避免各前端分别猜测字段。

### 测试覆盖限制

当前 D 测试覆盖功能和权限较完整，但没有并发库存、生产安全配置和大数据量分页性能测试。
