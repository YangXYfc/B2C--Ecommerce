## 1. 测试目标

验证消费者 Web 能否连接真实后端并完成商品浏览链路，同时检查页面品牌、接口数据适配、本地图片和生产构建。测试结果用于判断 A 角色是否达到“找商品→加购→下单→付款→看订单”的交付要求。

## 12. 已知问题

### A-API-001：消费者 Web 无法显示真实商品列表

- 严重程度：高。
- 复现率：100%。
- 后端事实：`GET /api/products?page=1&size=8&sort=sales` 返回 HTTP 200、`total=7`，数据数组字段为 `data.list`。
- 前端事实：`getProducts()` 只对 `(page.records || [])` 做转换。
- 用户影响：首页推荐、搜索结果和商品详情入口无法形成完整购物路径。
- 建议：由 A/D 共同确认分页契约，A 端兼容 `records` 与 `list`，并补充真实分页响应自动化测试。
