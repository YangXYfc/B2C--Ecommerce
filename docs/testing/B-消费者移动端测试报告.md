## 1. 测试目标

验证 uni-app 消费者移动端的核心购物流程、真实后端联调、本地图片、H5 构建和微信小程序编译，确认 Android App 与微信小程序共享的代码骨架能够运行。

## 2. 测试范围

- 登录、首页、搜索、商品列表、商品详情、SKU、购物车和结算入口。
- 分类、购物车、订单、退款、字段标准化、表单校验和 Mock 服务单元测试。
- 本地 `/media/` 图片解析及离线图片加载。
- H5 生产构建、微信小程序生产编译。
- B 与 D/E 真实接口的浏览器端联调。

## 3. 本次不测试的范围

- 未使用 HBuilderX 生成 Android APK，也未在真实 Android 设备安装运行。
- 微信小程序已完成生产编译，但未导入微信开发者工具进行真机授权、网络域名和支付能力验证。
- Playwright 流程到达“提交订单”页面，没有点击提交订单，因此未在开发库创建新订单。
- 未执行多设备兼容、弱网、性能、无障碍和生产签名测试。
